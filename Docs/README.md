# FaxFlow: Fax from iPhone & iPad

A modern, high-performance mobile fax machine app for iOS & iPadOS built with SwiftUI, VisionKit, PDFKit, and StoreKit 2.

## How to Build & Run
1. Install XcodeGen:
   brew install xcodegen
2. Generate project:
   xcodegen generate
3. Open FaxFlow.xcodeproj and run on iOS 17+ Simulator or Device.
