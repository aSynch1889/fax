# Product Requirements Document (PRD)

## Target App Reference
- Name: FAX from iPhone & iPad App
- Developer: BPMobile
- App Store URL: https://apps.apple.com/us/app/fax-from-iphone-ipad-app/id1135811739

## Core Features
1. Document Scanner & Input: VisionKit edge detection, photo library & PDF file picker.
2. Image Filter Pipeline: Original, B&W Fax, Grayscale, Enhanced Doc.
3. PencilKit E-Signature: Drawing pad, local storage, interactive page stamping.
4. Cover Page Designer: 4 templates (Professional, Modern, Minimalist, Urgent Priority).
5. Global Fax Dispatcher: 90+ country dialer, real-time transmission state machine, official confirmation receipts.
6. Address Book & History: Contacts directory, Outbox & Sent logs, QuickLook receipt preview.
7. StoreKit 2: Weekly, Monthly, Yearly subscriptions + 10, 50, 100 consumable credit packs.
8. Multi-Language: String Catalog supporting en, zh-Hans, zh-Hant, ja, ko.
9. Dark & Light Mode: Full Apple HIG compliance.
